A Project holds everything for a piece of delivery: Sprints, Tasks, files, milestones, and what your client sees. Everyone can use Projects. Admins, Managers, and project leads create and run them.

## Create a Project

<Steps>
  <Step title="Open Projects and choose Create">
    Or use the first-Project step during [onboarding](/get-started/onboarding).
  </Step>
  <Step title="Fill in the basics">
    Name, description, dates, and members. Optionally link a client.
  </Step>
  <Step title="Choose visibility">
    **Public** projects are visible to the organization. **Private** projects are limited to their members.
  </Step>
</Steps>

Each Project gets a readable ID such as `PAY-P-001`.

## Status

Projects move through **Planning → Active → Review → Completed**. You can also set per-project Task status labels.

A **health indicator** shows how the Project is going. It is calculated automatically, or you can set it by hand with a note. Clients can see a client-facing health note.

## Project tabs

| Tab | Use it for |
| --- | --- |
| **Overview** | Status, health, progress, and key details |
| **Sprints** | The Project's Sprints. See [Sprints](/features/sprints) |
| **Milestones** | Client-friendly stages. See [Milestones](/features/milestones) |
| **Updates** | Status posts for the client. See [Project updates](/features/project-updates) |
| **Team** | Who is on the Project |
| **Assets** | Files for the Project. See [Files](/features/files) |
| **Recurring tasks** | Repeating work. See [Recurring tasks](/features/recurring-tasks) |
| **Client** | What the client sees. See [Client sharing](/clients/client-sharing) |

**Settings** has four tabs: General, Team, Advanced, and [Credentials](/features/project-credentials).

## Limits and downgrades

Active Projects are limited by plan: **5** on Free, **30** on Starter, and **unlimited** on Pro and Max. After a downgrade, Projects over the limit become read-only. Nothing is deleted. See [Plan enforcement](/admin/billing/plan-enforcement).

Deleting a Project shows a preview of what goes with it. You can restore it from [Trash](/features/trash) within 30 days.
