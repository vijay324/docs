A Task is the basic unit of work. Flotick has two kinds, so you can pick the right amount of process.

## Two kinds of Task

| | **Sprint task** | **Individual task** |
| --- | --- | --- |
| Belongs to | A Sprint | No Sprint |
| Who sees it | The team | Only you, the creator |
| Flow | To do → In progress → Review → Testing → Done | To do → In progress → Completed |
| Roles | Assignee, reviewer, tester, reporter | None |
| Comments and files | ✓ | Not supported |
| Subtasks | ✓ | ✓ |

## Task fields

Title, description, Project, Sprint, status, priority, type, estimate or story points, due date, labels, and milestone. A type can be **Epic**, which groups child Tasks and shows their progress. Each Task gets an ID like `PAY-T-142`.

## Create a Task

<Steps>
  <Step title="Choose the Project">
    Start from the Inbox, Tasks, a Project, or a Sprint. You can also press **+** for [Quick Add](/get-started/navigation#quick-add).
  </Step>
  <Step title="Pick the kind">
    Leave Sprint empty for an individual task, or choose a Sprint.
  </Step>
  <Step title="Add detail">
    Set priority, type, estimate, due date, labels, and acceptance criteria.
  </Step>
</Steps>

Need a head start? [AI writing helpers](/features/ai-writing) can draft a Task from a title. You can also turn a [client request](/clients/client-requests) into a backlog Task.

## Find and manage work

The Tasks page has **List**, **Board**, **Backlog**, and **Calendar** views. Filter by Project, status, priority, assignee, Epic, overdue, and dates. Then:

- **Bulk edit** many Tasks at once
- **Drag** to rank or change status
- See the Task's **history**
- **Delete** to the Task trash (`/tasks/trash`) and restore later

## Subtasks

Break a Task into a simple checklist. Each item has a title and an optional note. Tick it to complete, and a progress bar shows done versus total. Needs permission to edit the Task.

<Note>
Members can delete Tasks only if they are Managers or have been granted permission. Tasks in a locked Project (after a downgrade) become read-only.
</Note>
