Credentials are encrypted logins and secrets stored with a Project: a hosting account, a CMS login, an API key. Everything the Project needs is in one place.

## Add and share

Open the Project, then **Settings → Credentials**. Add a credential and choose whether it is **visible to the client** in their portal.

## Stay in control

- Credentials are **encrypted**.
- Every **reveal is logged**, so you can see who looked.
- Access follows Project permissions.
- When someone leaves, [offboarding](/admin/offboarding) lists credentials you should rotate.

<Tip>
Share a credential with a client only when they need it. You can hide it again any time.
</Tip>
