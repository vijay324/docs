Project keys is a safe home for the `.env` settings your developers use. Values are encrypted, organized by Project, and versioned so you can always go back.

## How it is organized

**Project → codebase → environment → versioned configuration.**

Open **Files → Project keys** in the sidebar (`/env-storage`) and pick the Project and codebase you need.

## Save and roll back

Choose **Save and commit** to create a **read-only snapshot**. Later, you can return to any earlier snapshot if a change goes wrong.

## Access

Managers have full access. Members have none by default, but an Admin can grant them view access. See [Member permissions](/admin/member-permissions).

<Warning>
Never paste secrets into chat, comments, or Task descriptions. Keep them in Project keys or [Project credentials](/features/project-credentials).
</Warning>
