A project update is a short, honest status post for your client. It keeps them informed without a long email or meeting.

## What goes in an update

**Headline**, **health**, **summary**, **done**, **next**, **risks**, and **decisions needed**.

## Write one

<Steps>
  <Step title="Open the Project and choose Updates" />
  <Step title="Start blank, or choose Draft from this week">
    The draft is filled in from real Task activity. Edit it freely.
  </Step>
  <Step title="Preview as client">
    See exactly what the client will see.
  </Step>
  <Step title="Publish">
    The update appears in the client's portal. You can edit or **unpublish** it later, and see when the client **viewed** it.
  </Step>
</Steps>

<Note>
Nothing is published automatically. Publishing needs a client with [portal access](/clients/portal-access). Anyone who can edit the Project can draft, but only publishers (project lead, creator, Admin, or Manager) can publish.
</Note>

## Weekly update

Choose **Send weekly update** to post to the portal or create a document. You can also set a weekly reminder so updates never slip.
