Some work repeats: weekly reports, monthly invoices to prepare, daily checks. A recurring task creates an **assigned individual task** for you on a schedule.

## Set one up

<Steps>
  <Step title="Open the Project and choose Recurring tasks" />
  <Step title="Add the details">
    Title, description, and assignee.
  </Step>
  <Step title="Choose the cadence">
    **Daily**, **weekly**, or **monthly**, and the next run date.
  </Step>
</Steps>

## Manage schedules

You can **pause**, **resume**, **edit**, or **delete** any schedule at any time. Pausing stops new Tasks without losing the setup.

<Tip>
Give recurring tasks a clear title like "Weekly client report" so the generated Tasks are easy to spot.
</Tip>
