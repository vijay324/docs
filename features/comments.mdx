Keep the conversation next to the work so context never gets lost.

## What you can do

- Write with **Markdown**: bold, lists, links, and code.
- **Reply** in threads.
- Add **heart reactions** and emoji.
- **@mention** a teammate to notify them right away.

You will find comments on Task details, Sprint details, and in the [Inbox](/features/inbox) task view.

## Good to know

- Comments work on **Sprint tasks only**. Individual tasks do not have comments.
- You can post about **30 comments per hour**.
- Mentions create a [notification](/features/notifications) for the person tagged.

<Tip>
Use @mentions to ask a specific person a question, instead of leaving it for anyone to find.
</Tip>
