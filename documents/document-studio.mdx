Document studio is where you design once and apply everywhere. Find it in **Settings → Features → Document studio**. A guided first-run setup gets you started.

## What you can set

- **Brand kits**: logo, colors, fonts, header and footer text, number and date formats, signature or stamp, and business details
- **Templates and defaults** for each document type
- **Saved styles** to reuse across documents
- **Welcome document** for new clients
- **AI knowledge** that powers the [AI Builder](/documents/editor#ai-builder)
