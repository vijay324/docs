Documents is where every client-facing paper lives: quotations, proposals, agreements, letters, policies, certificates, handoff notes, and welcome documents. Start from a template and send in minutes.

## What you can create

- **Quotations and proposals**
- **Agreements**: contracts, NDAs, SLAs, DPAs, and more
- **Letters**, **policies**, and **certificates**
- **Handoff notes** and **welcome documents**

## The hub

Open **Documents** (`/documents`). Tabs are **All**, **Quotations**, and **Contracts**. Filter by **Sent** and **Accepted/Signed**. Old `/quotes` links redirect here.

## Template center

Open **Templates** to browse about **49 starter templates**, all available on **Free**. They are arranged by project stage:

1. Before you start
2. Make it official
3. Start the project
4. During the project
5. Get paid
6. Finish well

Plus **Team and HR**, **Policies**, and **Letters**. Start blank, start from a template, or import a Word, HTML, or text file.
