---

Press `?` anywhere in the app to see the shortcut list.

## Anywhere

| Shortcut | Action |
| --- | --- |
| `Ctrl/⌘ K` or `/` | Open search and commands |
| `[` | Collapse or expand the sidebar |
| `C` | Create |
| `⇧ C` | New Task |
| `?` | Show shortcuts |

## Go to a page

Press `G`, then a letter.

| Keys | Opens |
| --- | --- |
| `G` `I` | Inbox |
| `G` `T` | Tasks |
| `G` `P` | Projects |
| `G` `S` | Sprints |
| `G` `B` | Personal board |
| `G` `A` | Analytics |
| `G` `M` | Members |
| `G` `F` | Files |
| `G` `D` | Documents |
| `G` `L` | Leads |
| `G` `C` | Clients |
| `G` `O` | Messages |
| `G` `V` | Meetings |
| `G` `,` | Settings |
