Portal access gives each of your client's contacts a private sign-in to the [Client Portal](/portal/overview).

## Grant access

<Steps>
  <Step title="Open the client and choose Client Portal">
    Add the contact if they are not listed.
  </Step>
  <Step title="Grant access">
    Flotick creates a **username** and a **one-time password**.
  </Step>
  <Step title="Send the sign-in details">
    Send them by **email** or **WhatsApp**. The client must set their own password at first sign-in.
  </Step>
</Steps>

## Manage contacts

| Action | What it does |
| --- | --- |
| **Resend** | Sends the sign-in details again |
| **Pause or disable** | Stops access without deleting the contact |
| **Preview as client** | See the portal exactly as they do |
| **Notify client** | Send an update email with an optional note and project (up to 5 per contact per day) |
| **Set role** | **Approver** can decide. **Viewer** can only read. See [Contact roles](/portal/roles-and-branding) |
| **Ask a question** | Send the client a question to answer in the portal |
| **Request a file** | Ask for an upload |
| **Log a change** | Record a change request on the client's behalf |

You can also see how often each contact receives emails.

## Limits

Free allows **5 portal clients**. Starter, Pro, and Max allow unlimited.
