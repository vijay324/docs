Messages replaces scattered email and chat threads. Talk to clients, teammates, and groups without leaving Flotick.

## What you can message

- **Clients**, through their portal
- **Teammates**, one-to-one
- **Named groups**
- **Project topic threads** that clients can start

Filter by **All**, **Unread**, **Clients**, **Team**, or **Groups**.

## Features

- **End-to-end encrypted** messages and attachments
- Edit, delete, and add emoji
- Read state and notifications
- Clients see **Seen by the team** so they know you got it

<Note>
Encryption needs a one-time secure setup for each person, with a recovery option so you can read messages on a new device. Flotick guides you through it the first time you open Messages.
</Note>

A client thread needs that client to have [portal access](/clients/portal-access).
