Leads go cold quietly. Autopilot watches for you and nudges you before that happens.

## What it does

- **Flags stale leads** after a set number of days without activity. The default is **7 days**, and you can set a different number for each stage.
- **Suggests a next step** for each stale lead.
- **Sends owners a daily digest** of leads that need attention.
- **Drafts replies** with **Draft reply**. The AI writes a suggestion, and it is **never sent automatically**.

<Note>
AI drafts use [AI credits](/features/orbit#credits). You always review and send the reply yourself.
</Note>
