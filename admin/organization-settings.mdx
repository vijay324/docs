## Workspace general

Open **Settings → Workspace → General**. Admins edit, Managers view.

| Section | What you set |
| --- | --- |
| **Profile** | Name, logo, web address, type, industry, team size, work mode, country, timezone |
| **Plan** | Your current plan |
| **Credit usage** | AI credits used |
| **Monday founder brief** | See [Founder brief](/features/founder-brief) |
| **Client portal** | See below |
| **Data and privacy** | See [Data and privacy](/admin/data-and-privacy) |

## Client portal settings

Admins set the portal defaults in the **Client portal** card:

- **Share progress** on new client Projects (on by default)
- **Ask for feedback** at milestones (on by default)
- **Reply time** shown to clients
- **Default email frequency** for each client notification type

<Tip>
Turn off feedback prompts here if you do not want the "How is the project going?" question shown to clients.
</Tip>
