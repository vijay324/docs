Members is your people directory and admin toolbox.

## The three roles

| Role | Typical use |
| --- | --- |
| **Admin** | The owner. Full access, billing, and settings. |
| **Manager** | Runs delivery and people. |
| **Member** | Does the work. |

Each role has defaults and a ceiling. See [Member permissions](/admin/member-permissions) to adjust access.

### Default access at a glance

| Area | Manager | Member |
| --- | --- | --- |
| Tasks | Full | View, create, edit |
| Projects, Sprints | Full | View |
| Files | Full | View |
| Attendance | View, create, edit | View, create |
| Leave | Full | View, create |
| Leads, Clients, Meetings, Documents | Full | View, create, edit |
| Members | View, create, edit | None |
| Project keys | Full | None |
| Payroll | None (can be granted) | Own payslips only |

## Add people

- **Invite** by email. See [Accept an invitation](/get-started/accept-invitation).
- **Add member** directly.
- **Bulk import** from a CSV or XLSX file.

## The member page

Open a person to see tabs for **Projects, Sprints, Tasks, Analytics, Attendance**, and **Permissions**. You can:

- Edit details, role, and status
- Set employment info: employee ID, job type, department
- Reset a password
- **Transfer ownership** (Admin only)
- Soft delete and restore. If a member still owns open work, deleting opens [offboarding](/admin/offboarding) instead.

## Seats

Seats are limited by plan: **5** Free, **10** Starter, **30** Pro, **75** Max. See [Seat management](/admin/billing/seat-management).
