Labels keep tagging consistent: "Bug", "Design", "Client request". Everyone who can edit a Task can apply them.

## Manage labels

Open **Settings → Features → Labels**. Add a label, pick a color, and rename or remove labels as needed.

<Note>
Renaming or deleting a label does **not** change Tasks that already carry it.
</Note>
