## The bell

The bell in the portal header shows an **unread count** and a dropdown of recent notifications. Choose **Mark all read** to clear it.

## Emails

| Type | When it arrives |
| --- | --- |
| **Urgent items** | Right away (up to 6 an hour) |
| **Everything else** | A weekly digest, or daily if your service provider sets it |

Message emails never include the message text.

## For organizations

Admins set the default email frequency for each notification type in [Client portal settings](/admin/organization-settings#client-portal-settings).
